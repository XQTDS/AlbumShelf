# 2026-08-17-cover-local-cache

## 背景

数据库中专辑只保存封面 URL（`cover_url`，网易云 CDN 地址），渲染层 `<img :src="album.cover_url">` 每次都直接请求网络。后果：

- 断网/离线时封面全部无法显示
- 每次启动都要重新下载全部封面，浪费流量、滚动列表时首屏封面加载慢
- CDN 响应慢时列表出现大量空白占位

## 目标

- 主进程把封面图片下载并缓存到本地磁盘（`userData/covers/`）
- 渲染层通过自定义协议 `cover://` 加载封面：缓存命中直接读盘，未命中自动下载并写盘后返回
- 保持远程 URL 兜底：协议加载失败时回退到原始 `cover_url`，现有"补全缺失封面"流程不受影响
- 封面 URL 变化时缓存自动失效（文件名含 URL 哈希），无需改数据库表结构

## 非目标

- 不做缓存总量上限/LRU 淘汰（封面单张约 50~150KB，量级可控，后续需要再加）
- 不做启动时/补全后的批量预下载（后续可在本方案基础上扩展为完全离线浏览）
- 不缓存模态框（在线搜索、模糊匹配确认等）中展示的封面，仅缓存专辑主列表与详情面板
- 数据库不新增字段，不改动现有 IPC 接口
