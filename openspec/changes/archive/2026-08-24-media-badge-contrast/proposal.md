# 唱片墙介质角标对比度优化

## 背景

唱片墙卡片的实体介质角标（黑胶/CD/磁带）采用深色半透明底（`rgba(0,0,0,0.6)`）+ 写实图标。图标本身以深色系为主（黑胶为写实黑盘、磁带机身 `#31373d`），导致"深色图标 + 深色底 + 深色封面"三层对比度流失：深色封面的专辑上，角标底片融入封面、图标融入底片，几乎不可见。CD 图标因高光部分较浅稍好，但同样受封面颜色影响。

用户反馈该问题后，评估了三种方案：浅色徽章底（保留写实图标）、深底+反白单色图标、描边+发光。经用户评定，选定**浅色徽章底**方案。

## 目标

- 唱片墙介质角标在深色封面上清晰可辨（角标底与封面形成明暗对比）
- 浅色封面上角标同样可见（通过投影/描边与浅色封面分离）
- 三种介质图标（黑胶/CD/磁带）在浅色底上均有足够辨识度
- 保持图标写实风格与现有布局（左上角、24px、多枚并排、常驻显示）不变

## 非目标

- 不改动图标资产（MediaIcon.vue 内联 SVG 保持原样）
- 不改动表格视图「实体」列徽章（置于应用自身背景上，无此问题）
- 不改动详情面板「实体收藏」分段按钮（非封面叠加场景）
- 不做按封面亮度动态取色的自适应方案（每张封面 canvas 采样有性能成本，收益不成比例）
- 不改变左下角排序角标的深色样式（语义不同，视觉分层保留）

## 方案选型

方案对比详见 design.md。核心决策：角标底由深色改为浅色半透明，图标保持写实风格——改动最小（一处 CSS 规则），三种介质一次解决，且写实黑胶在浅底上比反白剪影更耐看。已由用户评定确认。
