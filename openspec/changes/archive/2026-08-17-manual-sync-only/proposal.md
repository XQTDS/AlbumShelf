# 2026-08-17-manual-sync-only

## 背景

当前应用在以下时机会自动触发全量同步（`ncm-cli album collected` 全量拉取约 1-2 分钟）：

1. **应用启动时**已登录 → 主进程发送 `auth:autoSync` → 渲染进程执行同步
2. **登录成功后** → `handleLoginSuccess()` 直接执行同步

每次启动/登录都跑一次全量同步耗时过长，且没有必要——用户需要时通过菜单栏「数据 → 同步专辑列表」手动触发即可。

## 目标

- 同步仅由手动入口（菜单栏「数据 → 同步专辑列表」）触发
- 登录成功只提示登录成功，不再自动同步
- 应用启动时已登录也不再自动同步
- 移除 `auth:autoSync` 事件通道及前后端相关代码

## 非目标

- 保留「未登录时启动显示登录引导」行为（`auth:loginRequired` 不动）
- 不改动同步流程本身
