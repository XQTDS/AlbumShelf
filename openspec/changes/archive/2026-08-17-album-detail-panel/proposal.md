# 2026-08-17-album-detail-panel

## 背景

详情抽屉首版为"点击行后从右滑入、宽度动画挤压列表"的实现。实测弹出/收回时表格 flex 重排，左侧列表项随宽度动画横移，体验不佳。用户决定改为**常驻面板**：面板恒定宽度、始终可见，表格布局永不变化。

## 目标

- 详情改为常驻右侧面板（宽度 `clamp(360px, 40vw, 620px)`），从工具栏以下开始，挤压布局但**宽度恒定**
- 点击列表项选中并刷新面板内容；再点同一行取消选中回到占位态
- 未选中时面板显示占位提示（"点击左侧专辑查看详情"）
- 头部常驻：选中时显示专辑名/艺术家 + ✕；✕ 与 Esc 均可取消选中
- 面板内容切换、选中/取消选中均**无任何布局动画**

## 非目标

- 不做手动收起面板（面板始终占据固定宽度）
- 不自动选中第一条专辑
- 不改详情内容本身（封面、风格编辑、评分、元数据、外链、重新同步、修改 ID、曲目列表均原样迁移）
