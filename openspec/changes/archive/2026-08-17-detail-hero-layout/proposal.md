# 2026-08-17-detail-hero-layout

## 背景

详情面板内容为纯纵向单列布局：140×140 封面在顶部居中偏左，风格标签、评分、元数据、外链依次堆叠在下方。面板宽度可达 620px（`clamp(360px, 40vw, 620px)`），宽面板下封面右侧约 300–440px 空间完全空白，布局松散、观感不佳。

## 目标

- 详情内容顶部改为 **hero 两栏布局**：封面居左并放大，风格标签、我的评分、元数据、外链/操作按钮移入右侧信息列
- 封面尺寸随面板宽度流体伸缩（约 140–240px 正方形），无需媒体查询
- 曲目列表保持在 hero 下方、面板全宽展示

## 非目标

- 不改面板宽度与常驻行为（选中/取消/切换仍无布局动画）
- 不改曲目列表、占位态、面板头部的任何结构与交互
- 不改详情内容本身（风格编辑、评分、外链、重新同步、修改 ID 均原样迁移）
