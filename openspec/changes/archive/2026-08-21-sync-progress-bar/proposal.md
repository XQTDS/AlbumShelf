# 2026-08-21-sync-progress-bar

## 背景

全量同步（`ncm-cli album collected` 分页拉取全部收藏专辑）耗时约 1-2 分钟。当前同步流程中 UI 只有一条静态提示「正在同步专辑数据...」，用户无法判断同步进展到哪一步、是否仍在运行，体验与自动补全流程（`enrich:progress` 实时进度条）不一致。

## 目标

- 同步期间在页面顶部显示与补全流程同款样式的进度条
- 拉取阶段（专辑总数未知）：显示「正在获取收藏专辑列表…已获取 X 张」，进度条为不定长动画
- 写入阶段（总数已知）：显示「正在同步专辑 X/Y 张」，进度条按比例填充
- 同步结束（成功或失败）时清除进度条，最终结果仍由现有消息提示展示

## 非目标

- 不改变同步流程本身（分页大小、重试、增量去重、删除清理均不动）
- 不改变「同步仅手动触发」行为
- 不改动补全/封面/发行日期回填的进度条实现
