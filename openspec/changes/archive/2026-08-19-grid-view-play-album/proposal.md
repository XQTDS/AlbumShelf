# 唱片墙播放整张专辑

## 背景

表格视图每行专辑名左侧有常驻 ▶ 按钮，可一键播放整张专辑（`handlePlayAlbum` → `player:playAlbum`）。唱片墙（网格）视图没有该入口：用户在唱片墙浏览时想播放整张专辑，只能先切换回表格视图，或选中专辑后在详情面板逐曲播放。

当时唱片墙的 spec（album-list-ui「悬停显示信息」）明确约定悬停遮罩不显示播放按钮，是为了保持封面干净；现在补上播放入口的需求，采用右下角悬停小按钮方案（用户已从四个备选方案中选定），在不动遮罩中央区域的前提下提供与表格视图一致的播放能力。

## 目标

- 唱片墙卡片悬停时，右下角显示小号 ▶ 按钮（与左下角排序角标对称、互不遮挡）
- 点击 ▶ 直接播放整张专辑，复用现有 `handlePlayAlbum` 播放链路（含主进程登录态处理、曲目入库兜底、队列快照与播放条展示），不改变卡片选中状态
- 播放发起中（`playingAlbumId === album.id`）按钮禁用并显示 spinner，与表格视图按钮行为一致

## 非目标

- 不改变表格视图的播放入口与行为
- 不在悬停遮罩中央增加播放按钮（遮罩继续仅展示专辑名与艺术家）
- 不做右键菜单、详情面板播放按钮等其他入口
- 不改变唱片墙卡片点击选中/取消选中的交互
- 不触碰播放链路（ncm-cli / IPC / 播放条），本次为纯渲染层入口

## 方案选型

四个备选方案（悬停中央播放按钮 / 右上角悬停小按钮 / 右键菜单 / 详情面板按钮）已由用户评定，最终选择：**右下角悬停小按钮**。
