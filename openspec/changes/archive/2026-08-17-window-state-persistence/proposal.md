# 2026-08-17-window-state-persistence

## 背景

应用启动时固定以 1200×800 创建主窗口（`src/main/index.ts` 的 `createWindow`）。用户手动调整窗口尺寸/位置后，下次启动仍恢复默认尺寸，调整结果丢失，每次都要重新调整。

## 目标

- 关闭窗口时将当前窗口的位置、尺寸与最大化状态保存到本地文件
- 下次启动时按上次关闭时的状态恢复窗口
- 显示器环境变化（显示器拔出/分辨率改变）导致保存的位置不可见时，回退到默认尺寸，避免窗口出现在屏幕外

## 非目标

- 不引入第三方依赖（如 electron-window-state），沿用项目现有「userData 目录 + JSON 文件」模式自行实现
- 不做崩溃恢复（仅在窗口正常关闭时保存）
- 不保存多窗口布局（应用目前只有一个主窗口）
