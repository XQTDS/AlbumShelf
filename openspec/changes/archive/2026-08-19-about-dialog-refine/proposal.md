# 关于弹窗微调

## 背景

关于弹窗首次实现后，用户反馈两处调整：

1. 弹窗内已有 GitHub 仓库跳转按钮，菜单栏「帮助 → 访问 GitHub 仓库」入口冗余，应删除
2. 弹窗缺少对软件现状问题的说明，用户不了解 MusicBrainz 数据补全与内置播放的局限，容易产生困惑

## 目标

- 移除「帮助」菜单中的「访问 GitHub 仓库」菜单项（保留弹窗内按钮作为唯一仓库入口）
- 在关于弹窗新增「已知问题」分区：
  - MusicBrainz 搜索算法与收录库有限，部分专辑匹配不到；缺失风格标签时建议参考 RateYourMusic 手动添加（RYM 有访问保护无法自动抓取，故数据源选用 MusicBrainz）
  - 应用内播放基于 ncm-cli，与网易云音乐 App 相比存在较多版权缺失；点击播放无反应时建议移步网易云 App 播放

## 非目标

- 不改动弹窗其余内容与样式基调
- 不改变 GitHub 仓库地址与菜单栏其他项
