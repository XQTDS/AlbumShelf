# album-detail-release-date

## 背景

详情面板元数据区展示「MB 评分 / 评分人数 / 曲目数 / 总时长」，缺少专辑的发行时间（`release_date`，列表已有「发行日期」列，数据格式为 `YYYY-MM-DD`）。用户希望在详情页补充展示。

## 目标

- 元数据区新增「发行日期」项，位于「评分人数」之后（评分块与曲目块之间），直接展示 `release_date` 原文，与列表列格式一致
- `release_date` 为空时显示"—"

## 非目标

- 不改列表列、不改数据同步/补全逻辑
- 不对日期做额外格式化（存储值已是 `YYYY-MM-DD` 字符串）
- 不改元数据区其余项与布局
