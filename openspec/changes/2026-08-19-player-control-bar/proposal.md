# 播放控制条（底部常驻播放条）

## 背景

应用内播放基于 ncm-cli（`player:playAlbum` / `player:playSong`），但渲染层没有任何播放状态展示：播放开始后无法暂停、无法切换上一首/下一首、看不到播放进度，只能等待整张专辑放完或直接退出应用。经实测验证，内置 ncm-cli 0.1.6 已完整提供 `pause / resume / next / prev / seek <秒> / state` 命令（`state` 返回 `status / title / position / duration / currentIndex / queueLength`），无需升级依赖或改造播放后端。

## 目标

- 底部常驻播放条（播放会话存在时显示，停止后隐藏），包含：
  1. 播放/暂停按钮（`pause` / `resume`）
  2. 上一首/下一首按钮（`prev` / `next`，队列边界时给出友好提示）
  3. 进度条：已播时长/总时长展示，点击进度条跳转（`seek`）
  4. 正在播放的专辑名/歌曲名/艺术家展示（本地播放上下文 + `state.title` 兜底）
  5. 音量控制（`volume 0-100` 滑块 + 图标静音切换，应用本地管理音量并在播放会话启动时应用）
- 播放状态自适应轮询（播放中 1s、暂停中 3s、停止即停），进度条在轮询间隔内平滑插值

## 非目标

- 不实现播放模式切换（随机/顺序/循环）
- 不实现歌词展示
- 不读取/同步播放器后端当前音量（ncm-cli 无音量读取命令，`state.volume` 恒为 null）：音量由应用本地管理（localStorage 记忆，会话启动时应用到后端），外部修改音量不与 UI 同步
- 不处理「播放会话由应用外启动（终端 ncm-cli）」的完整追踪——仅用 `state` 信息兜底展示歌曲名/艺术家，专辑名展示为「—」
- 不改变既有 `playAlbum`（清队→首曲→入队）与退出时停止播放的行为
