# 专辑实体介质标记（黑胶/CD/磁带）

## 背景

用户收藏实体唱片（黑胶、CD、磁带），需要在 AlbumShelf 中记录"我拥有某张专辑的哪种实体介质"。当前专辑数据全部来自网易云/MusicBrainz 在线数据，没有"实体收藏"这一私人维度。

已有的「我的评分」功能（user-rating spec）证明了用户自定义字段的完整技术路径：SQLite 列迁移 + 同步不覆盖 + IPC 写入 + 详情面板交互组件 + 列表只读展示。实体介质标记与该路径完全同构。

## 目标

- 用户在专辑详情面板中标记该专辑拥有的实体介质：黑胶 / CD / 磁带，**可多选**（同一专辑可同时标记多种，如同时拥有黑胶与 CD）
- 标记持久化到本地数据库，同步/补全/重新同步操作不覆盖用户标记
- 标记在列表项上可见：
  - 表格视图：新增「实体」列，显示介质徽章，无标记显示 —
  - 唱片墙视图：卡片左上角显示介质徽章（多枚并排）
- 标记可随时增删（点击切换），操作路径与「我的评分」一致（乐观更新 + 失败回退）

## 非目标

- 不做按介质筛选（可作为后续迭代）
- 不做按介质排序
- 不记录实体版本、品相、价格等收藏元数据（仅介质类型）
- 不改变同步/补全链路（新字段仅由用户在详情面板编辑）

## 方案选型

三个 UI 设计维度已由用户评定：

1. **数据模型**：多值，可同时标记多种介质（一张专辑可同时是黑胶+CD）
2. **详情面板控件**：方案A 分段按钮组（三枚图标按钮一排，点击切换，选中态填充高亮）
3. **表格视图展示**：新增「实体」列（位于「我的评分」列之后）

唱片墙视图展示位置（卡片左上角）为唯一空闲角落：左下角被排序角标占用、右下角为悬停播放按钮，无需用户决策。
